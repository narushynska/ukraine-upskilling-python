# Ukraine Upskilling: Python

Навчальні матеріали курсу **AI Programming in Python** (програма цифрового перекваліфікації для українських жінок, біженок і ВПО).

## Що тут є

| Файл | Що це |
|---|---|
| `dates_in_pandas.py` | Дати в Pandas: тип `datetime64`, `to_datetime`, формати `%d.%m.%Y`, `.dt`, `NaT`, групування за місяцями. Файл поділено на клітинки (`# %%`), їх можна запускати по одній у VS Code |

## Як скачати

**Найпростіше (без Git):** зелена кнопка **Code** → **Download ZIP** → розпакуйте папку.

**Командою:**

```bash
git clone https://github.com/narushynska/ukraine-upskilling-python.git
cd ukraine-upskilling-python
```

**GitHub Desktop:** File → Clone repository… → вкладка URL → вставте адресу вище → Clone.

## Як запустити

1. Потрібен Python 3 і pandas: `pip install pandas`.
2. Для прикладів із даними покладіть поруч файли `service_requests.csv` і `food_waste_dataset.csv` із теми 3 курсу. Без них код використає вбудовану маленьку таблицю, а блок про Food Waste пропустить.
3. Запуск усього файла: `python dates_in_pandas.py`. Або відкрийте файл у VS Code (з розширенням Python/Jupyter) і натискайте **Run Cell** над кожною клітинкою.
